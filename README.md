# CCEH-Cisco
Ethical Hacking - Labs &amp; Notas

Este repositorio contiene mis apuntes, prácticas de laboratorio y scripts relacionados con el **hacking ético, ciberseguridad y automatización**.  
El objetivo es documentar y compartir, a criterio propio, los principales ejercicios realizados en entornos controlados (VMs de Kali Linux y laboratorios de Cisco/NetAcad).

## Contenido

- **Módulo 3** – Certificados SSL y OSINT con `crt.sh`
- **Módulo 3** – Captura y análisis de tráfico con `tcpdump` y **Wireshark**
- **Módulo 4** – Ingeniería social con **SET (Social Engineering Toolkit)**
- **Módulo 5** – Enumeración de SMB con **enum4linux** y `smbclient`
- **Módulo 10** – Automatización con scripts en **Bash, Python, Ruby y PowerShell**

## Tecnologías y herramientas usadas

- Kali Linux
- Wireshark / tcpdump
- Nmap / enum4linux
- Social Engineering Toolkit (SET)
- Bash, Python, Ruby, PowerShell

## Disclaimer

Todo el material aquí documentado está orientado a **fines educativos y de práctica en entornos controlados**.  
No debe usarse en sistemas de terceros sin autorización expresa.

## Objetivos

- Reforzar conocimientos de **ciberdefensa y pentesting**
- Documentar prácticas para un portafolio técnico
- Facilitar la reutilización de scripts y metodologías
